# 制定训练建议

目标是提供可执行的训练建议，不是直接保存或激活计划。同一个 Skill 适用于胸、背、腿等目标。

1. 确认目标部位、可用器械、经验、时间和相关身体限制。请求明确但条件缺少时，具体询问必要条件，不让用户重述目标。可以在明确标注假设后给通用方案。
2. 按需用 fitness.query 读取训练相关档案和训练记录，不为训练建议擅自读取饮食明细。没有权限时说明需要用户通过应用授权，禁止自行授予。
3. 需要动作规则时 knowledge.search 检索并引用来源；只读必要资料，不加载所有 Skill。
4. 动作、组数、次数、休息和时长作为建议结构交给 fitness.calculate 的 validate_training 验证。失败时在剩余预算内调整或说明冲突，不发布未验证建议。
5. 最终给出准备活动、动作安排、休息和停止条件。只使用校验结果的 suggestion_markdown 展示数字建议，引用对应证据ID；不要改写成用户已经完成的事实。
6. 使用用户语言。完整计划用详细回答，快捷解释简短。不要编造训练重量、身体能力或已保存状态。

疼痛或其他风险先按系统健康政策处理，不诊断、不鼓励忍痛继续。没有已知限制不等于证明没有限制。正式写入不属于本 Skill 权限；不执行任何脚本。
